# SOC Home Lab

## Overview

This project documents the creation of a Security Operations Center (SOC) Home Lab using Kali Linux and Ubuntu Server running in VirtualBox.

The lab was built to practice real-world SOC analyst skills including network monitoring, host enumeration, log analysis, authentication monitoring, web server monitoring, and intrusion prevention.

## Lab Architecture

- Host System: MacBook Air M4
- Kali Linux (Analyst Workstation)
- Ubuntu Server (Target Server)

## Tools Used

- Kali Linux
- Ubuntu Server
- VirtualBox
- Nmap
- Wireshark
- OpenSSH
- Apache2
- Fail2Ban
- Git & GitHub
